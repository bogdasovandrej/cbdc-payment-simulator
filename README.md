# Симулятор оплаты по QR-коду

Pet-проект, сделал чтобы попрактиковаться в SQL и PostgreSQL.

Модель сервиса приёма платежей в цифровых рублях: пользователь выставляет счёт,
к нему создаётся QR-код, платёж проходит статусы
`CREATED → PROCESSING → PAID / FAILED`, при успешной оплате деньги
зачисляются на кошелёк.

## Файлы

- `01_schema.sql` — таблицы: пользователи, кошельки, платежи, QR-коды, транзакции
- `02_data.sql` — тестовые данные: 50 пользователей и 1000 платежей за 30 дней
- `03_payment_flow.sql` — один платёж от создания до зачисления на кошелёк
- `04_analytics.sql` — аналитика:
  1. распределение платежей по статусам
  2. конверсия в успешную оплату
  3. среднее время обработки
  4. динамика по дням
  5. средний чек
  6. топ-10 пользователей
  7. сверка балансов кошельков с транзакциями

## Запуск

```
createdb cbdc
psql -d cbdc -f 01_schema.sql
psql -d cbdc -f 02_data.sql
psql -d cbdc -f 03_payment_flow.sql
psql -d cbdc -f 04_analytics.sql
```
